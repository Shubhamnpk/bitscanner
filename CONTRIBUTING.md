# Contributing to BitScanner

Thank you for your interest in contributing to BitScanner!

## Development Setup

1. Fork and clone the repository:
   ```bash
   git clone https://github.com/Shubhamnpk/bitscanner.git
   cd bitscanner
   ```
2. Install dependencies:
   ```bash
   bun install
   ```
3. Start the dev server:
   ```bash
   bun run dev
   ```

## Running Tests

Run the test suite before submitting pull requests:
```bash
bun test
```

## Pull Request Guidelines

- Ensure all existing tests pass and add new unit tests for new functionality.
- Follow the existing code style and naming conventions.
- Keep client-side security and zero-telemetry privacy principles intact.
